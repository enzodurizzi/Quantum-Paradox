# 🌌 Quantum Paradox: O Enigma da Singularidade

Este é um jogo de lógica dedutiva desenvolvido em **Python** focado na resolução de paradoxos temporais por meio de pistas geradas de forma dinâmica.

## 🏫 Contexto do Projeto
Desenvolvido como projeto prático para a disciplina de **Programação**, referente ao **2º Ano do Ensino Médio**. O objetivo principal é aplicar conceitos de lógica estruturada, manipulação de coleções de dados (listas e dicionários) e geração de elementos aleatórios em Python.

## 🛠️ Como Executar o Jogo
Como este projeto foi desenvolvido para rodar em computadores escolares, você pode testar o código copiando o conteúdo de `quantum_paradox.py` e colando diretamente em um executor online de Python, como o [Trinket](https://trinket.io) ou [Replit](https://replit.com).
